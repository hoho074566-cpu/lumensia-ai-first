# R3R UI Note

- `admin ...` and `admin: ...` are hidden diagnostic prefixes. They render into an `ADMIN PREVIEW · 세이브 미변경` section and do not mutate the saved run.
- Generated scene blocks end with a compact copy control modeled on the supplied overlapping-squares reference. It copies the scene output only, with narration and speaker names/dialogue in readable text order.
- Admin previews are session-only and disappear on reload/new game/import; canonical save/export remains untouched.
