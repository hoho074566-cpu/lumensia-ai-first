# V0 Pure Original Feel Core — Human Acceptance

## Acceptance bar

PASS is not “비슷하다”, “좋아졌다”, or “원작을 잘 흉내 냈다”.

PASS only when sustained play naturally produces the conviction:

> **이거 원작인데?**

If comparison remains conscious, the gate is not yet passed.

## What this branch deliberately keeps small

- Pure V0 one-Writer-call architecture
- Canon facts + bounded relevant/ambient character signals
- minimal PC↔NPC familiarity / affinity / stance / notable context
- NPC knowledge boundary: System knows PC ≠ NPC knows PC
- persistent PC residence fact across A/B/C halls
- Continue / Admin Preview / Copy UX

No Event Director, scheduler, event queue, NPC spawn table, rotation index, hook score, attention meter, event-density score, time engine, scene state machine, or extra model call.

## Core narrative gate

Use ordinary inputs. Do not name NPCs just to force them on screen.

Suggested opening stress path:

1. `입학식에 들어간다`
2. Continue button as needed; do not type a fake PC action merely to finish an already-live ceremony.
3. `기숙사로 가서 짐을 푼다`
4. `학교를 둘러본다`
5. `기사과 훈련장으로 간다`
6. `잠시 지켜본다`
7. `점심을 먹으러 간다`
8. `오티로 간다`
9. `지시를 따른다`
10. `나도 자세를 잡고 선다`
11. Continue button if the live interaction has more reactions that need no PC choice.
12. `그 뒤 며칠은 특별한 계획 없이 지낸다`

### PASS signals

- connective movement/admin is fast while meaningful scenes get room to breathe;
- prose density changes with importance instead of every paragraph receiving the same polished weight;
- no bare timestamp prose such as `08:55.` or `09:15.` even though continuity time stays accurate;
- NPCs are already living their own lives;
- NPC desire sometimes becomes concrete initiative: question, challenge, invitation, argument, warning, request, departure, investigation, training, etc.;
- when that desire intersects the PC, the NPC acts on it instead of remaining decorative;
- the PC is not CCTV, but the world also does not become a mechanical protagonist magnet;
- Canon Named NPCs carry personal/recurring roles while unnamed people still populate the world;
- dialogue sounds character-specific and in-the-moment rather than polished thematic speeches;
- quiet scenes exist as contrast, but quiet play does not freeze the world indefinitely;
- distinct Canon phases remain distinct rather than orientation/lunch/practice being fused by momentum;
- combat shows adaptation, physical geometry, power gaps, attrition, and consequence;
- failure/injury/equipment/reputation/institutional aftermath persists when earned.

### CORE FAIL

- the user must repeatedly request every interesting event;
- NPCs populate the scenery but rarely initiate anything;
- the PC remains irrelevant for multiple scenes despite visible, character-relevant causes for reaction;
- every NPC mechanically approaches the PC;
- generic newly named characters take recurring roles from the Canon cast;
- all departments are silently sent to A hall;
- residence changes between turns;
- bare clock-state numbers leak into prose;
- major characters repeatedly deliver generic GPT-style life lessons;
- every paragraph has the same smooth descriptive density;
- Continue is recorded as a new PC action;
- Admin Preview mutates save/history/time/relationships;
- copy control copies the wrong block or includes unrelated UI text.
