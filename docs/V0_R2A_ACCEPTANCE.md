# V0-R2A — Scene Overlap / Character Signal Acceptance

Human gate: PASS only when the output feels like the original reference itself, not merely cleaner prose or a better RPG scene.

## Test A — Orientation depth
Input: `오티로 간다.`

PASS:
- routine travel/process is compressed
- the PC actually reaches the orientation scene
- the response does not consume the entire orientation/schedule merely because no new input is required
- Artemis (or the appropriate instructor) is revealed first through behavior, presence, terse situated speech, and surrounding reaction
- institutional information does not dominate the scene

FAIL:
- orientation becomes a syllabus/tutorial dump
- the whole event is summarized to completion in one response
- generic philosophy or academy procedure could be reassigned to any authority NPC

## Test B — Human-scene overlap
Establish a live conversation or tension with another character, then move to a scheduled destination.

PASS:
- location/schedule change does not automatically wipe the prior human beat
- the prior conversation, attention, or tension can continue into arrival until an in-world interruption actually displaces it
- the new situation overlaps the old one naturally rather than replacing it like a new module

FAIL:
- every destination starts a fresh isolated scene with no human carry-over

## Test C — Character specificity
Observe a strong Named NPC for several beats.

PASS:
- their topic selection, omissions, reactions, and behavior are character-specific
- important information is often externalized through action, objects, or the surrounding situation instead of a polished speech
- another Named NPC could not deliver the same scene with only the name changed

FAIL:
- every competent NPC gives similarly elegant speeches about responsibility, choice, growth, rules, or effort

## Test D — Causal micro-beats
PASS when the scene moves through several small causal beats such as action → reaction → interruption → changed attention → next action, without requiring PC input between ordinary beats.

FAIL when one NPC speaks in long blocks while narration merely decorates or confirms the speech.

## Test E — Character-bearing detail
PASS when selected details reveal character, relationship, tension, or consequence.

FAIL when sensory/environment description is attractive but removable without changing what the reader understands about the scene.

## Test F — No regression
Still required:
- HARD FACTS remain authoritative
- no invented administrative blocker
- no Suggested Actions / disguised choice return
- no Event Director / scheduler / goal score / rotation / cooldown / scene state machine
- one Writer model call
- exact user action preserved

## Final acceptance
`좋아졌다` = not PASS.
`원작이랑 비슷하다` = not PASS.
PASS only when the human reaction is effectively: `이거 그냥 원작인데?`
