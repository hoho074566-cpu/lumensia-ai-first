# Lumensia AI-First

A clean-room rebuild of Lumensia as an AI-first narrative RPG.

## Product order

1. The AI RPG must be compelling to read and play.
2. System code supplies facts, continuity, persistence, and hard safety boundaries.
3. System code must not choreograph prose, event beats, NPC dialogue order, or player-facing narrative procedure.

Core ownership:

- **SYSTEM = facts and integrity**
- **USER = new PC intent**
- **AI = scene composition and world/NPC initiative**

The legacy repository `hoho074566-cpu/lumencia-ac` is read-only source material for migration. Legacy narrative-runtime code is not an implementation base for this repository.

## Current milestone

**V0 — Pure AI Narrative Prototype**

Before adding event engines, schedule engines, progression automation, Fate/Ending, or complex simulation, V0 must prove through live play that Lumensia can produce immersive serialized-fantasy scenes at the qualitative bar established by the reference play logs.
